Formation intensive

Maîtriser Claude Code

Deux journées pour passer de la première commande à l'automatisation complète de vos workflows de développement avec l'agent en ligne de commande d'Anthropic.

⏱️ 2 jours · 14 h 👥 Dev & tech leads 💻 Pratique 70 % 🎯 Du débutant à l'avancé

À qui s'adresse cette formation ?

Développeur·euse·s, ingénieur·e·s et tech leads qui veulent intégrer l'IA agentique à leur quotidien. Aucune expérience préalable de Claude Code n'est requise — une aisance avec le terminal et Git suffit.

Prérequis techniques

Node.js 18+, un terminal, un dépôt Git, et un compte Anthropic (Claude Pro/Max) ou une clé API.

Objectif final

Être autonome pour coder, déboguer, refactorer et automatiser avec Claude Code — en local comme en CI.
